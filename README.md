# Cuubik es un plugin spigot/paper desarrollado en java y maven, para integrar la API de Gemini en el cual se usa el chatbox de minecraft para interactuar acerca del juego, como conseguir materiales, minerales, crafteos y demas dudas

# Installation
Ya que esta en fase beta el plugin por temas de seguridad para los usuarios no se ha publicado oficialmente en la pagina de Spigot para su uso dentro del juego sin embargo, al descargar el repositorio puedes usarla desde el cmd, recuerda tener la version de java mas actualizada en tu PC y el servido local de Paper

Una vez descargado lo necesario, dentro del mismo hay un archivo run.bat el cual ejecuta el servidor local, tomara unos segundos, cuando finalize "Done" en las ultimas lineas podras usar el comando "g como craftear una espada" gemini le tomara unos segundos por el alto flujo en el uso de la API y te respondera

Recuerda que debes solicitar tu API_KEY en el Gemini IA Studio y configurarla en el archivo java del plugin
